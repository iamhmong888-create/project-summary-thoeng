# ระบบสรุปผลการดำเนินโครงการ (สกร.ระดับอำเภอเทิง)

ระบบนี้มี 2 หน้า
- **`index.html` สำหรับผู้เรียน:** เลือกโครงการ แล้วทำแบบทดสอบก่อนเรียน แบบทดสอบหลังเรียน และแบบประเมินความพึงพอใจ โดยไม่ต้องล็อกอิน
- **`admin.html` สำหรับครูและแอดมิน:** ล็อกอินด้วย **ชื่อ** (ไม่ต้องมีคำนำหน้าและนามสกุล) และใช้ **เบอร์โทร** เป็นรหัสผ่าน ใช้สร้างโครงการ แบบทดสอบ และแบบประเมิน ดูผล และออกรายงาน Word

## ไฟล์ในชุดนี้
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าผู้เรียน |
| `admin.html` | หน้าครูและแอดมิน |
| `app.js` | โค้ดของระบบ (ใช้ร่วมกันทั้งสองหน้า) |
| `style.css` | หน้าตาของระบบ |
| `logo.png` | โลโก้หน่วยงาน (แสดงที่แถบหัวและปกรายงาน) |
| `config.js` | **ไฟล์เดียวที่ต้องแก้:** ใส่ค่า Firebase |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล |

> **ไม่ต้องอัปโหลดไฟล์ Excel รายชื่อบุคลากรขึ้น GitHub** เพราะทุกคนจะเปิดดูเบอร์โทรได้ ให้นำเข้าผ่านหน้า "ตั้งค่าระบบครั้งแรก" แทน

## สิทธิ์ผู้ใช้
| สิทธิ์ | ทำอะไรได้ |
|---|---|
| ครู | สร้างและแก้ไขโครงการ แบบทดสอบ และแบบประเมิน ดูผล ออกรายงาน และบันทึกผลจากแบบฟอร์มกระดาษ |
| ผู้ดูแลระบบ (แอดมิน) | ทำได้ทุกอย่างที่ครูทำได้ เห็นทุกโครงการ เพิ่ม ลบ หรือเปลี่ยนสิทธิ์บุคลากร (ตั้งครูเป็นแอดมินได้) แก้รายการห้องเรียนและครูประจำกลุ่ม และตั้งค่าหน่วยงาน |

ตอนนำเข้า ผู้ที่มีตำแหน่ง "ผู้บริหาร" และ **วนศาสตร์** จะได้สิทธิ์ผู้ดูแลระบบอัตโนมัติ และเปลี่ยนสิทธิ์ภายหลังได้ที่เมนู **บุคลากร**

---

## ติดตั้ง (ประมาณ 20–30 นาที)

### 1) สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com → **Add project**
2. **Build → Firestore Database → Create database** เลือก `asia-southeast1` และ production mode
3. แท็บ **Rules** → วางเนื้อหาจาก `firestore.rules` → **Publish**
4. **Build → Authentication → Get started** → เปิดใช้ **Email/Password**
   (ระบบใช้ชื่อแปลงเป็นอีเมลภายในให้อัตโนมัติ ผู้ใช้ไม่ต้องรู้อีเมล)
5. ⚙️ **Project settings → Your apps → `</>`** สร้าง Web app แล้วคัดลอกค่า `firebaseConfig`

### 2) ใส่ค่าใน `config.js`
แก้บรรทัด `window.FIREBASE_CONFIG = null;` เป็นค่าที่คัดลอกมา

### 3) อัปโหลดขึ้น GitHub Pages
1. สร้าง repository ใหม่ (Public) แล้วอัปโหลด `index.html` `admin.html` `app.js` `style.css` `config.js` `logo.png`
2. **Settings → Pages →** branch `main`, โฟลเดอร์ `/ (root)` → Save
3. ใน Firebase ไปที่ **Authentication → Settings → Authorized domains** แล้วเพิ่ม `<ชื่อผู้ใช้>.github.io`

### 4) นำเข้ารายชื่อบุคลากร (ทำครั้งเดียว และควรทำทันทีหลังติดตั้ง)
1. เปิด `https://<ชื่อผู้ใช้>.github.io/<repo>/admin.html#setup`
2. กด **เลือกไฟล์ Excel** แล้วเลือกไฟล์รายชื่อบุคลากร (ต้องมีหัวตาราง `ชื่อ` และ `เบอร์โทร`)
3. ตรวจรายชื่อและสิทธิ์ แล้วกด **สร้างบัญชีทั้งหมด**
4. เมื่อเสร็จ ทุกคนล็อกอินได้ทันทีด้วยชื่อและเบอร์โทรของตัวเอง

### 5) ตรวจรายการห้องเรียน
แอดมินไปที่เมนู **ห้องเรียน** ตรวจชื่อศูนย์และชื่อครูประจำกลุ่ม (มีค่าเริ่มต้น 22 ห้อง) แก้ไข เพิ่ม หรือลบ แล้วกด **บันทึก**
รายการนี้จะเป็นตัวเลือก "เรียนอยู่ห้องเรียน" ในแบบทดสอบและแบบประเมินของผู้เรียน

### 6) ใช้งาน
- **ลิงก์ผู้เรียน:** `https://<ชื่อผู้ใช้>.github.io/<repo>/`
- **ลิงก์ครูและแอดมิน:** `https://<ชื่อผู้ใช้>.github.io/<repo>/admin.html` (หน้าผู้เรียนไม่มีลิงก์ไปหน้านี้ ครูควรบันทึกเป็นบุ๊กมาร์ก)

1. ครูล็อกอินที่ `admin.html` → **+ โครงการใหม่** → บันทึก
2. ในหน้าโครงการ กด **+ สร้างแบบทดสอบ** แล้วพิมพ์หรือวางข้อสอบตามรูปแบบนี้

   ```
   1. คำถามข้อที่ 1
   ก. ตัวเลือก
   *ข. ตัวเลือกที่ถูก
   ค. ตัวเลือก
   ง. ตัวเลือก
   ```
3. เปิดหรือปิดรับ **ก่อนเรียน / หลังเรียน / ประเมินความพึงพอใจ** ได้จากปุ่มในหน้าโครงการ
4. ให้ผู้เรียนสแกน QR Code ซึ่งจะพาไปที่ `index.html` ของโครงการนั้น
   ผู้เรียนกรอกคำนำหน้า ชื่อ-สกุล รหัสนักศึกษา ระดับชั้น และห้องเรียน **ระบบใช้รหัสนักศึกษาจับคู่คะแนนก่อนและหลังเรียน** จึงต้องกรอกรหัสให้ถูกต้องทั้งสองครั้ง
5. ถ้าใช้แบบฟอร์มกระดาษ ครูกดปุ่ม **บันทึก… (กระดาษ)** แล้วคีย์คำตอบแทนผู้เรียนได้
6. กด **รายงานสรุปผล → ดาวน์โหลด Word** จะได้รายงานที่มีผลทดสอบก่อน-หลังเรียน (ตารางสรุป คะแนนรายบุคคล และร้อยละที่ตอบถูกรายข้อ) และผลความพึงพอใจครบ

## หมายเหตุสำคัญ
- **ความปลอดภัย:** การใช้เบอร์โทรเป็นรหัสผ่านสะดวก แต่คนที่รู้เบอร์ก็ล็อกอินได้ ระบบนี้จึงเหมาะกับข้อมูลโครงการทั่วไป ไม่ควรเก็บข้อมูลลับในระบบ
- **เปลี่ยนเบอร์โทรหรือลืมรหัส:** เข้า Firebase Console → Authentication → ลบผู้ใช้คนนั้น แล้วให้แอดมินเพิ่มชื่อใหม่ในเมนู **บุคลากร**
- **ชื่อซ้ำ:** ระบบล็อกอินด้วยชื่อ จึงต้องไม่มีชื่อซ้ำกัน ถ้าซ้ำ ให้แก้ชื่อในไฟล์ Excel ให้ต่างกัน เช่น เติมอักษรนามสกุล
- **การแสดงคะแนนทันที:** ถ้าเปิดไว้ เฉลยจะถูกส่งไปที่เครื่องผู้เรียนด้วย ถ้าไม่ต้องการ ให้ปิดในหน้าแก้ไขแบบทดสอบ แล้วดูคะแนนได้ที่ฝั่งครูเท่านั้น
- **แก้ข้อสอบหลังมีผู้ทำแล้ว:** แก้ได้แค่ถ้อยคำหรือเฉลย ห้ามเพิ่ม ลบ หรือสลับลำดับข้อ
- **โหมดทดลอง:** ถ้า `config.js` เป็น `null` ระบบจะเก็บข้อมูลในเบราว์เซอร์เท่านั้น ใช้ทดลองก่อนติดตั้งจริง
